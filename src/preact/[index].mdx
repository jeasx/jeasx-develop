# Use Preact with Jeasx

[Preact](https://preactjs.com) lets you embed interactive islands into server-rendered pages. Components keep their own state, and signals let separate islands share state across the page.

<details>
<summary>How do I integrate Preact with Jeasx?</summary>
Install Preact, its signals and the server renderer:

```bash
npm install @preact/signals preact preact-render-to-string
```

Preact brings its own JSX runtime, so add a `tsconfig.json` to the folder that holds your Preact components:

```json
{
  "extends": "jeasx/tsconfig.json",
  "compilerOptions": {
    "jsxImportSource": "preact"
  },
  "include": ["**/*"]
}
```

Have a look at the [source code of this page](https://github.com/jeasx/jeasx-expo/tree/main/src/preact) to see how the components are rendered on the server and mounted in the browser.

</details>

## World clocks

Each clock is a separate island, but all of them read the same signal, so they always tick together. Use this pattern whenever separate islands on a page need to share state.
