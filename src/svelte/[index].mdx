# Use Svelte with Jeasx

[Svelte](https://svelte.dev) is a UI framework with a compiler: you write components in HTML, CSS and JavaScript, and Svelte turns them into small bundles that do little work in the browser. Jeasx renders them on the server and hydrates them in the browser.

<details>
<summary>How do I integrate Svelte with Jeasx?</summary>
Install Svelte and its esbuild plugin:

```bash
npm install svelte esbuild-svelte
```

Then register the plugin for the server and the browser build in `jeasx.config.js`:

```js
export default {
  // The server imports this config at startup too, so import build-only plugins lazily:
  // loading the Svelte compiler would slow down every server start.
  ESBUILD_SERVER_OPTIONS: async () => {
    const { default: sveltePlugin } = await import("esbuild-svelte");
    return {
      plugins: [sveltePlugin({ compilerOptions: { generate: "server", css: "external" } })],
    };
  },

  ESBUILD_BROWSER_OPTIONS: async () => {
    const { default: sveltePlugin } = await import("esbuild-svelte");
    return {
      plugins: [sveltePlugin({ compilerOptions: { generate: "client", css: "external" } })],
    };
  },
};
```

With `css: "external"`, the styles of all components imported by a browser bundle end up in a CSS file next to it (e.g. `index.css` next to `index.js`). Link it in your page, so the components are styled right away, even before hydration and without JavaScript.

View the [source code of this page](https://github.com/jeasx/jeasx-expo/tree/main/src/svelte) for an implementation of a Svelte integration with hydration support. Feel free to improve it as you like.

</details>
